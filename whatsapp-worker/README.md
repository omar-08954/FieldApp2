# FieldApp WhatsApp Worker

عامل منفصل يستخدم جلسة WhatsApp Web لإرسال تقارير FieldApp تلقائيًا. لا يتم حفظ جلسة QR أو الأسرار في Git.

شغّل `npm install` ثم انسخ `.env.example` إلى `.env` واضبط عنوان API والسر المشترك. يمكن أن تكون `WHATSAPP_REPORT_RECIPIENTS` أرقامًا شخصية بصيغة دولية بدون `+` أو معرّفات مجموعات تنتهي بـ `@g.us`. شغّل `npm start` وامسح QR من سجلات الطرفية أول مرة؛ سيطبع العامل أسماء المجموعات ومعرّفاتها، ويجب أن يكون رقم العامل عضوًا في المجموعة.

الخدمة تحتاج تشغيلًا دائمًا ومجلد `auth` دائمًا؛ إذا حُذف المجلد أو أعيد تشغيل الخدمة دون تخزين دائم فستحتاج لمسح QR مرة أخرى.
